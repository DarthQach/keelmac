# Changelog

All notable changes to KeelMac. Versions follow [Semantic Versioning](https://semver.org).

## [Unreleased]
### Added
- Projects: pick the folders where your projects live and see which are on GitHub and untouched (safe to remove), which have work only on this Mac (with the reasons), and which aren't in git. Move proved projects to the Trash, or back them up to a private GitHub repository with your gh login after a preview of every command. Verify with GitHub is off by default.
- Assistant: choose Ollama or LM Studio in Settings › Assistant › Server. Each keeps its own address; KeelMac picks Ollama unless only LM Studio is installed.
- Assistant: when the chosen app isn't installed, the panel says so and links to its download; when the other app is installed, it offers to use that one instead.

## [1.0.0]
First release: dashboard with Health Score and load line, menu bar monitor, storage map (treemap and sunburst), large and old files, System Data breakdown, safe cleanup with preview and Trash-first deletion, operation log, app uninstaller, leftovers, login items, maintenance tasks with a privileged helper, duplicates, weekly snapshots and reports, English and Spanish.
