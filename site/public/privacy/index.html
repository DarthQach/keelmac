Privacy

KeelMac runs entirely on your Mac. It has no account, no analytics and no telemetry.

What leaves your Mac

Only the update check: once a day (if automatic updates are on) KeelMac downloads appcast.xml from this site to see whether a new version exists. Sparkle’s anonymous system profile is turned off. This site’s host, Cloudflare, sees the request like any web request.

What stays on your Mac

Scan results, the operation log, weekly snapshots and settings are stored in ~/Library/Application Support/KeelMac and in KeelMac’s preferences. Delete the app and that folder to remove everything.

File contents

KeelMac reads file names, sizes and dates. It reads file contents only when you search for duplicates, to compare files byte for byte, and never sends them anywhere.

Contact

Questions or a privacy concern: open an issue on GitHub.
