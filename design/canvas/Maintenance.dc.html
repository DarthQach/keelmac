Maintenance

Helper installed. Admin tasks run without a password prompt.
Flush DNS cacheAdmin
Clears cached name lookups. Useful after changing networks, VPNs or your hosts file.
dscacheutil -flushcache; killall -HUP mDNSResponder
Rebuild Launch Services database
Fixes duplicate apps in “Open With” menus and wrong default apps.
lsregister -kill -r -domain local -domain system -domain user
Rebuild Spotlight indexAdmin
Erases and rebuilds the index for Macintosh HD. Search results are incomplete for about an hour.
mdutil -E /

Clear font caches
Removes your font cache. Fixes garbled or missing fonts. Restart afterwards.

Thin local Time Machine snapshotsAdmin
Asks macOS to free up to 20 GB held by local snapshots. Your backups on the backup disk aren’t affected.
tmutil thinlocalsnapshots / 20000000000 4
