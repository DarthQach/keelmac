How KeelMac keeps your files safe

  • Every cleanup starts as a preview. Nothing outside the preview is touched.
  • Items go to the Trash first. Permanent delete is a setting you turn on yourself.
  • System folders, other users’ homes, iCloud Drive, Photos and Mail are protected in code.
  • Your whitelist is checked on every delete, including admin tasks.
  • Every action is written to an operation log you can read and export.

Free, with no catch

No subscription, no account, no telemetry. The only network request KeelMac makes is the update check. The code is on GitHub under the GPL-3.0 licence, and cleanup rules are a JSON file anyone can improve.

Questions

Does KeelMac speed up my Mac by freeing RAM?

No. macOS manages memory well on its own. KeelMac shows memory pressure so you can see when an app is the problem, and lets you quit it.

Why does it ask for Full Disk Access?

Many caches and logs live in folders macOS protects. Without access KeelMac still works, but it skips those folders and tells you which ones.

What does the helper do?

A few tasks, like rebuilding the Spotlight index, need administrator rights. The helper can only run the named tasks listed in the app, and checks every path again before touching it.

Is it on the Mac App Store?

No. The App Store sandbox doesn’t allow an app to clean caches across your Library. Download it here or with Homebrew.
