# Code of conduct

KeelMac is a small open-source project. Everyone who takes part (issues, pull requests, discussions) is expected to:

- Be kind and assume good faith. Critique code and ideas, never people.
- Keep discussions on topic and in plain language. English or Spanish are both welcome.
- Respect people's time: search existing issues first, give enough detail to reproduce.
- Not harass, insult, or publish anyone's private information.

The maintainer may edit or remove comments and block participants who don't follow this. To report a problem privately, contact the maintainer through the address in SECURITY.md.
